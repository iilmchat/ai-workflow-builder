# Памятка: CDP-смоук браузерного UI (KI-264)

Настоящие скрипты смоука живут **вне репозитория** (временные файлы), поэтому
в репо фиксируются только правила, без которых прогон даёт ложный результат.
Памятка дополняет RULES § 4.33 («smoke-проверки требуют снимка состояния до»).

## 1. Fetch-перехват — только API

Слишком широкий `Fetch.requestPaused` (например, `url.includes('/workflow')`)
перехватывает модули Vite: `/src/stores/workflow.ts`, `/node_modules/`,
`?import`. Подмена ответа на `application/json` ломает загрузку модуля —
холст не рендерится, и смоук падает «не по теме».

Пропускать без перехвата:

- `/src/`, `/node_modules/`, `/@vite/`, `/@fs/`;
- запросы с `?import`, `?t=`;
- всё, что не похоже на API-ручку (`/workflow`, `/runs`, `/auth`, `/llm`, …).

Правило: перехватывать **конкретный path + method**, а не подстроку URL.

## 2. Синтетические клавиши

- `Input.dispatchKeyEvent` для печатаемых клавиш — `type: 'keyDown'` **с полем
  `text`**. Вариант `rawKeyDown` в части прогонов не доходит до страницы
  (0 `keydown`).
- Для модификаторов и служебных клавиш обязателен
  `windowsVirtualKeyCode`; иначе часть нажатий теряется, а повторные
  переключатели (`H`/`M`/`Tab`) «дожимают» состояние обратно.
- Перед вводом проверить `document.visibilityState`: в видимом Chrome с
  `document.hidden === true` OS-ввод молча отбрасывается (см. KI-275).
- `Page.captureScreenshot` снимает фокус с активного элемента — после
  скриншота повторно наложить фокус / `Page.bringToFront`.

## 3. Импорт модуля стора из страницы

`import('/src/stores/workflow.ts')` создаёт **второй экземпляр** zustand-стора,
если Vite выдал приложению URL с `?t=<timestamp>` после инвалидации. Берём URL
из `performance.getEntriesByType('resource')` — он содержит реальный `?t=`.

## 4. Заголовки запросов

`Network.requestWillBeSent` **не содержит** `Authorization`, даже при валидном
токене. Для проверки «Bearer ушёл» использовать
`Network.requestWillBeSentExtraInfo` или `Fetch.requestPaused`.

## 5. Хуки после F5

Хук, который должен работать после перезагрузки (перехват кадров SSE, запись
`console.log`), ставится через `Page.addScriptToEvaluateOnNewDocument`.
Иначе восстановленная подписка стартует раньше инъекции и кадры теряются.

## 6. Две ловушки ввода (KI-286)

- `Input.dispatchKeyEvent` с полем `text` для **модифицированных** сочетаний
  (`Ctrl+A`) вставляет символ `a` в пустое поле. Для «выделить всё / очистить
  поле» вместо эмуляции печати используйте
  `DOM.setSelectionRange({ nodeId, start: 0, end: length })` (или
  `Runtime.evaluate` с `select()`).
- Пункты каталога ниже `max-h-80` находятся вне видимой области: перед кликом
  по координатам вызовите `scrollIntoView({ block: 'center' })` в
  `Runtime.evaluate` и только потом считайте `elementFromPoint` — иначе
  клик попадает в контейнер скролла.

## 7. `/unknown/foo` — 404 не всегда

Vite в SPA-режиме (`appType: 'spa'`) отвечает на неизвестный путь по-разному:

- для не-HTML запроса (например, `fetch('/unknown/foo')` без
  `Accept: text/html`) — **404**;
- для навигации документа (`Accept: text/html`) — **200 text/html**
  (SPA-fallback, штатное поведение).

Поэтому проверка «`/unknown/foo` → 404» корректна **только для fetch**.
Не используйте её как универсальный smoke-чек навигации (KI-313).

## 8. Минимум инфраструктуры (KI-396)

CDP-смоук `/runs` требует Docker/WSL с PostgreSQL (5433) и Redis (6379) —
без Redis BullMQ падает `ECONNREFUSED`, и backend не сможет поставить задание
в очередь. Это инфраструктурное требование, не дефект кода: graceful-режим
без Redis не вводится (KI-019 — fail-fast Redis PING на старте). Перед
приёмочным смоуком на новом хосте проверить `docker compose ps` и доступность
обоих портов.

## 9. Минимальный чек-лист прогона

1. Снимок состояния **до** действия (RULES § 4.33).
2. Открыть страницу, дождаться рендера холста (не только `DOMContentLoaded`).
3. Выполнить действие, снимок **после**, сравнить.
4. Проверить консоль на `error` (401 на неаутентифицированном заходе —
   известный шум, KI-226/KI-351).
5. Для клавиатурных сценариев — проверить фокус и `visibilityState`.
