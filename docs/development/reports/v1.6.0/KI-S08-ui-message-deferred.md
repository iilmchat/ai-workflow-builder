## 3. Диагностика

- **KI-119** подтверждён: `findImageNodesWithoutModel` считает все image-узлы
  «без модели», когда `mediaModels = []` или каталог ещё не загружен.
- **KI-106:** дедупликация по `runId:nodeId` защищает повторы воркера; новый
  runId — осознанный новый запуск, дополнительный ключ нужен только при жалобах.
- **KI-107:** лимиты media-upstream неизвестны без ключа; семафор вслепую
  уменьшит throughput.
- **KI-131:** `expectTypeOf` без отдельного tsc-гейта по спекам ничего не
  гарантирует; generic-хелпер — большой diff по всему реестру узлов.

## 4. Smoke

Проверка i18n-паритета (новый ключ есть в обоих файлах) и сборка web.
UI-сценарий с пустым каталогом проверяется по коду: ветка выбирает новый текст,
когда `!mediaModelsLoaded || mediaModels.length === 0`.

## 5. Что не так

- KI-106/107/131 остаются Deferred — это осознанный приоритет, триггеры
  возврата зафиксированы в реестре.
- Новый i18n-ключ не покрыт отдельным component-тестом (TopBar.spec.tsx не
  тестирует handleRun) — паритет ключей проверяется тестом i18n.
