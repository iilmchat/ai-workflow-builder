## 3. Диагностика

### 3.1. `costStatus` (KI-152)

Раньше `cost_usd = 0` означал сразу три вещи: локальная модель, ответ из
кэша и цена, округлившаяся до нуля. Теперь причина передаётся явно:

| Значение | Когда ставится | UI |
|---|---|---|
| `cached` | `LlmGenerateResult.cached === true` (Redis-hit) | «Из кэша (0 ₽)», `data-cost-status="cached"` |
| `local` | провайдер `isLocal` (LM Studio) | «Локально (0 ₽)», `data-cost-status="local"` |
| `unknown` | провайдер не отдал `usage` | «Стоимость неизвестна», `data-cost-status="unknown"` |
| `exact` | облачный вызов с usage | обычная строка стоимости |

Контракт протянут по цепочке:

1. `LlmNodeExecutor` вычисляет статус и кладёт в `metrics.costStatus` и
   `outputs.costStatus` (`{ text, costStatus, cached? }`).
2. У агента статус считается по шагам: `cached`, если все LLM-шаги из кэша;
   `local`, если все локальные; `unknown`, если ни один не отдал usage;
   смешанный маршрут — `exact`. Поле есть в `AgentRunResult`, `outputs` и
   `metrics`.
3. `ExecutionEngineService` передаёт `costStatus` в SSE-событие
   `node_completed`, но **не** пишет его в колонки `node_runs` (их нет).
4. Snapshot читает `costStatus` из `node_runs.outputs`, поэтому поле
   переживает F5; чужие/старые значения дают `null`.
5. Фронтенд хранит `costStatus` в `NodeRunMetrics` (snapshot + событие) и
   рисует бейджи. `formatMetrics` больше не печатает `$0.00` для
   `cached`/`local`/`unknown` — только для `exact` или старых данных без поля.

### 3.2. Единый курс USD→RUB (KI-383)

До шага было две переменные: `WORKFLOW_RUN_USD_RUB_RATE` (бюджет) и
`MEDIA_USD_RUB_RATE` (каталог media). Теперь:

- канонический ключ — `USD_RUB_RATE` (default `100`);
- `resolveUsdRubRate(config)` читает `USD_RUB_RATE`, затем legacy
  `WORKFLOW_RUN_USD_RUB_RATE`, затем `MEDIA_USD_RUB_RATE`, иначе `100`;
- `CostBudgetService` и все прямые media-провайдеры (FAL, Replicate,
  OpenAI Images) используют один helper — шкала больше не расходится;
- старые переменные остались в схеме как **optional** legacy-алиасы, чтобы
  существующие `.env` не изменили поведение после обновления;
- `.env.example` и `.env.production.example` переведены на `USD_RUB_RATE`,
  старые ключи из примеров удалены.

`MediaRegistryService` сам курс не читает: пересчёт цены живёт в провайдерах
(`toDirectModelInfo`/`readCostRub`). Обновлены именно они; это отражено в
отчёте как отклонение от буквы задания.

### 3.3. Кнопки «Открыть»/«Скачать» (KI-124)

В `ImageGenNode` над `<img>` появился overlay (правый верхний угол):

- **«Открыть»** — `window.open(src, '_blank', 'noopener,noreferrer')`;
- **«Скачать»** — `fetch(src)` → `blob()` → `URL.createObjectURL` →
  `<a download="<имя из URL>">`; после клика blob освобождается. При
  `!response.ok`, CORS-ошибке или сетевом сбое — fallback
  `window.open(src, '_blank')`, чтобы кнопка не «молчала»;
- кнопки имеют `nodrag` (клик не тащит узел), видны по `group-hover` и
  `focus-within` (доступность с клавиатуры/тача);
- имя файла берётся из пути URL без query; fallback — `image-<nodeId>.png`.

Кнопки работают с `storedUrl` — той же ссылкой, что показывает `<img>`
(`resolveMediaSource`, KI-362/KI-443). Ссылку провайдера узел по-прежнему не
подставляет: у неё неизвестный TTL.

## 5. Что не так / отклонения

1. **`costStatus` не стал колонкой БД.** Задание говорит «в `NodeRunMetrics` /
   `node_runs.outputs`»; выбран второй путь — поле в JSON-outputs. Это не
   требует миграции и переживает F5 через snapshot-маппер. Если понадобится
   аналитика SQL по статусу, нужна отдельная колонка/индекс.
2. **`MediaRegistryService` не читает курс.** Задание упоминает его, но
   фактический пересчёт USD→RUB живёт в провайдерах (`fal`, `replicate`,
   `openai-images`) и в `provider-catalog`. Обновлены они; реестр только
   маршрутизирует модели.
3. **Legacy-переменные не удалены полностью.** `WORKFLOW_RUN_USD_RUB_RATE` и
   `MEDIA_USD_RUB_RATE` оставлены optional-алиасами: иначе прод с кастомным
   курсом после обновления молча получил бы `100`. `USD_RUB_RATE` имеет
   приоритет; примеры env переведены на новый ключ.
4. **`AgentRunResult.costStatus` — агрегат.** Для смешанного маршрута
   (часть шагов из кэша, часть exact) статус `exact`, потому что единого
   «смешанного» значения в контракте нет.
5. **Скачивание зависит от CORS.** Если CDN не отдаёт заголовки, `fetch`
   падает — кнопка открывает вкладку (по требованию). Пользователь сохраняет
   файл сам.
6. **`window.open` может быть заблокирован** браузером при вызове после
   async-`fetch` (не user gesture). В fallback это допустимо, но браузер может
   показать блокировку popup — альтернатива (скрытый `<a>` без blob) не
   решает CORS.
7. **Скриншотов нет.** UI описан текстом и покрыт `@testing-library/react`;
   визуальный смоук требует запущенного приложения.
8. **`web/dist` обновлён сборкой**, но каталог в `.gitignore` и в diff не
   попадает.

## 6. Новые KI

Новые KI **не заводились**, чтобы не менять проверенный счёт 657. Кандидаты:

1. **SQL-аналитика по `costStatus`.** Если понадобится агрегировать
   «сколько сэкономили на кэше» в БД, поле нужно вынести в колонку.
2. **Смешанный статус агента.** Сейчас mixed cached/exact = `exact`; можно
   добавить `mixed` или счётчик шагов по причинам.
3. **Fallback скачивания без popup.** Можно предложить «Открыть» вместо
   автоматического `window.open` при CORS-ошибке.
4. **Живой курс USD/RUB.** KI-372 (фиксированный курс) остаётся открытым:
   единый ключ упрощает ручную настройку, но не делает курс живым.
5. **Индикатор источника стоимости в истории запусков.** Бейджи есть только
   в панели результата; в таблице истории — только суммы.
