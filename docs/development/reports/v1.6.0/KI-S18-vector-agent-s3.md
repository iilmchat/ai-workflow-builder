## 7. Обоснование решений

Для S3 зафиксирована инфраструктурная ответственность (lifecycle) — это
исключает попытки «починить» удаление в коде, где ключ объекта нельзя
использовать как локальный путь. Остальные KI требуют метрик или смены
публичных контрактов.
