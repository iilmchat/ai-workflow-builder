## 3. Диагностика

- **KI-056:** `LlmController.listModels()` уже открывает `GET /llm/models`,
  отдавая `registry.listModels()`; web использует эту ручку. KI устарел.
- **KI-060:** `Last-Event-ID` действительно не обрабатывается, но
  `RunsStreamService` первым сообщением отдаёт полный снимок из БД —
  финальное состояние не теряется.
- **KI-050:** `inputs_hash` потребовал бы миграции `node_runs` и канонического
  сериализатора. Входы уже ограничены (HTTP 1 МБ, KI-025), выигрыш мал.
- **KI-053:** учёт стоимости неудачных попыток требует таблицы
  `node_run_attempts` и правила суммирования без двойного счёта.

## 7. Обоснование решений

Статусы Deferred/Won't Fix применены только там, где правка либо не нужна (функция уже
есть, состояние компенсируется снимком), либо несёт миграцию/изменение
биллингового контракта без измеримой пользы на текущем масштабе (RULES 3.1:
маленькие шаги, без смешивания несвязанных изменений).
